# 오늘의길

오늘 걷기 좋은 길을 추천해주는 산책 코스 앱 (Next.js + Kakao Map).

## 실행

```bash
npm install
npm run dev
```

→ http://localhost:3000

> **중요: 반드시 3000 포트로 실행해야 합니다.**
> 카카오 개발자 콘솔에 `http://localhost:3000` 도메인만 등록되어 있어,
> 다른 포트에서는 Kakao Map SDK가 401로 거부됩니다.
> 다른 포트/도메인을 쓰려면 [developers.kakao.com](https://developers.kakao.com) →
> 앱 설정 → 플랫폼 → Web 사이트 도메인에 추가하세요.

## 환경 변수

`.env.local`

```
NEXT_PUBLIC_KAKAO_MAP_KEY=<카카오 JavaScript 키>
NEXT_PUBLIC_CARTO_API_KEY=<CARTO basemaps API 키 (선택)>
OPENAI_API_KEY=<아이콘·장소명 이미지 분석용 서버 키 (선택)>
OPENAI_VISION_MODEL=gpt-4.1
```

`NEXT_PUBLIC_CARTO_API_KEY`는 분석용 CARTO 래스터 타일 요청에 사용합니다. 키 발급과 사용 조건은
[CARTO 공식 안내](https://carto.com/basemaps/apikey/)를 확인하세요. 워터마크나 지도 스타일 변경은 픽셀 분류에 영향을 줍니다.

`OPENAI_API_KEY`는 서버에서만 읽습니다(`NEXT_PUBLIC_` 접두사를 붙이지 마세요).
설정하면 장소명·아이콘이 포함된 지도 PNG를 OpenAI Responses API로 보내 자연물·건물·아이콘의 영역과 유형을 읽습니다.
추가 API 호출 비용이 발생합니다. 키가 없거나 분석이 실패하면 지형/도로 분석만 사용하며,
카페처럼 의미 인식이 필수인 조건은 생성 실패로 안내합니다. 이미지에 없는 장소를 보완하지 않습니다.

## 인터랙션

- 우상단 알림/설정, 하단 '코스 추천받기' 버튼을 누르면 iOS 다이나믹 아일랜드처럼
  버튼 자리에서 검정 패널이 스프링으로 확장되고, 닫으면 다시 버튼으로 줄어듭니다
  (`motion`의 shared `layoutId` + `AnimatePresence`).
- '오늘의길' 버튼은 어떤 상태에서도 유지되며 클릭 시 패널·시트를 닫고 지도를 초기 위치로 되돌립니다.
- 스크림 클릭 또는 `Esc`로도 패널을 닫을 수 있습니다.

지도는 드래그 이동, 휠/핀치 제스처 확대·축소가 가능합니다.
추천 코스 말풍선 마커를 클릭하면 하단에 코스 설명 시트가 열리고,
지도 빈 곳을 클릭하면 닫힙니다.

## 코스 생성: 이미지 → 요소 → 웨이포인트 → 길

외부 POI 검색이나 도로 네트워크 API 없이, 현재 위치 주변 **래스터 지도 이미지**로 코스를 생성합니다.
지역별 고정 코스 데이터는 생성에 사용하지 않습니다. 시작 시 기기 위치를 확인하며 위치 권한을 얻지 못하면 안내합니다.

1. **스냅샷** — 현재 위치·희망 시간으로 Web Mercator 범위를 고정하고 CARTO 타일을 하나의 이미지로 합칩니다.
   도로 분석에는 `voyager_nolabels`, 의미 분석에는 같은 범위·해상도의 `voyager`를 사용합니다.
   카카오 화면의 DOM 스크린샷은 아닙니다. 카카오맵은 결과 표시를 담당하고 분석용 지도에는 CARTO 출처를 표시합니다.
2. **요소 분리** — 무라벨 이미지의 픽셀을 길·물·녹지·건물 등으로 분류합니다.
   비전 API는 유라벨 이미지에서 자연물·건물·아이콘의 영역, 유형, 장소명, 신뢰도를 반환합니다.
   반환 박스가 이미지 범위를 벗어나거나 신뢰도 0.8 미만이면 제외합니다. 이는 객체 영역 인식이며,
   아이콘의 픽셀 단위 마스크나 모든 지도 스타일에 통용되는 학습형 세그멘테이션은 아닙니다.
3. **전략 구성** — 현재 위치 근처의 길에 출발점을 놓고, 이어진 길로 도달 가능한 후보와 도로거리를 구합니다.
   시간에 맞는 순환 코스를 목표로 카테고리별 경유지와 길의 비용을 정합니다.
4. **카테고리 필터** — 녹지·물가·건물·아이콘의 근거를 선택 조건과 대조합니다.
   카페는 식별된 카페 아이콘/장소명이 있어야 하며 건물 밀집도로 대체하지 않습니다.
   여러 조건을 선택하면 후보는 합집합으로 모으되 최종 코스에는 **각 조건을 충족하는 경유지가 모두** 있어야 합니다.
5. **웨이포인트 선택** — 이미지 속 요소를 주변 길에 스냅하고, 도달 불가 후보를 제외합니다.
   의미 인식된 장소는 60m 이내 길만 사용하며 장소 중심으로 직선을 그리지 않습니다.
6. **길 연결** — 길 셀 위에서만 A*로 경유지를 연결하고 출발점으로 돌아옵니다.
   녹지 전체·고속화도로는 통행면으로 취급하지 않으며, 장애물 모서리 대각선 통과와 선 단순화에 의한 지름길을 막습니다.
   선택한 경유지 연결에 실패하면 그 경유지를 몰래 버리지 않습니다.
7. **완성/검증** — 모든 조건의 방문 여부·닫힌 경로·목표 길이를 검증한 뒤 선과 경유지를 표시합니다.
   4km/h 기준 시간, 이미지 좌표로 측정한 거리, 출발점과 현재 위치의 차이를 안내합니다.
   목표 길이 ±10%를 지향하고 최대 ±30%까지 수락합니다. 실패하면 코스를 만들지 않고 재시도 안내를 표시합니다.

분위기 `quiet/lively/night`는 지도 형태의 대리 지표이며 소음·유동인구·조명 확인을 뜻하지 않습니다.
`hill/flat`은 선택적으로 Terrarium **고도 래스터 이미지**를 읽으며 결손을 평지로 판단하지 않습니다.
도로의 실제 보행 허용 여부, 출입구, 입체 교차, 공사·통제는 이미지에서 확인할 수 없습니다.
현재 픽셀 팔레트는 CARTO Voyager 전용입니다. 다른 지도 스타일은 별도 팔레트/세그멘테이션 어댑터가 필요합니다.
줌아웃된 지도에 아이콘/작은 길이 보이지 않으면 해당 요소를 사용할 수 없습니다.

- 구현: `lib/route/tiles.ts`, `vision.ts`, `elements.ts`, `strategy.ts`, `pipeline.ts`, `graph.ts`, `loop.ts`
- 비전 서버: `app/api/route/segment/route.ts` — PNG/크기 검증, 동일 출처 검사, 취소/45초 제한, 프로세스당 동시 2건/분당 10건.
  다중 인스턴스 배포 시 비용 상한은 플랫폼의 전역 요청 제한으로 관리해야 합니다.
- 생성 잡: 한 번만 실행, 새 요청 시 기존 요청 취소, 전체 60초 제한, 타원 폴백 없음.
- 재현: `?debug=1&seed=42`; 개발 전용 `/dev/seg?lat=37.5485&lng=126.9335&minutes=30&tags=river&seed=42`.
  디버거에서 원본 스냅샷, 분류 이미지, 요소 박스, 필터 전후 후보 수, 누락 조건, 최종 경로를 확인할 수 있습니다.
